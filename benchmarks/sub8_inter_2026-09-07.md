# Sub-8 inter partitions and visible chroma edges

Base: `1d5a6e04e80216b1063faa3baa7cbb2189d132f3`. Found while wiring
animated AVIF color formats in cavif-rs. Honoring the default 4:4:4 setting
made the existing explicit 4x4 partition override reach an inter-frame panic.

## Causes and corrections

- Both partition searches refused sub-8 inter splits for every format other
  than 4:2:0. An explicit maximum of 4x4 required a split that the guard
  prohibited, leaving no valid partition. Mono and 4:4:4 require no shared
  chroma prediction; the restriction now applies only to 4:2:2, whose
  shared-chroma prediction remains unsupported.
- In 4:2:0, a 4x4 partition outside the visible luma area can own chroma
  shared with its visible neighbor. Pixel and skip-transform distortion
  must clip each plane independently at its aligned origin. Returning zero
  for invisible luma also discarded visible chroma error.
- Scalar weighted SSE used full-window iterators. Those omitted incomplete
  4x4 chunks at the visible edge. A one-column chroma block consequently
  returned zero error despite retaining the previous frame's samples.
  The corrected loop includes partial chunks and preserves the existing
  per-chunk fixed-point scaling and rounding.

The initial 65x67, 8-bit, bottom-up 4:2:0 witness differed in frame 1's
rightmost chroma column. Encoder reconstruction was already wrong, and
the decoded sample was the previous frame's value (13 below the source).
The partition guard change alone and the plane-clipping change alone did
not fix it; including the partial SSE chunks did.

## Source and decoder checks

`tests/sub8_inter_roundtrip.rs` covers 144 configurations / 288 frames:
mono/420/444, 8/10/12-bit, top-down/bottom-up partition search,
Psychovisual/PSNR, and 65x67, 67x65, 68x68, 64x64 dimensions. Every
configuration explicitly forces 4x4 partitions and lossless coding. Both
encoder reconstruction and rav1d-safe decoding must equal the original
visible samples on every plane. All passed.

`SUB8_INTER_ARTIFACTS` exports each stream and its native-depth source
planes. `scripts/verify_sub8_inter.py` independently decoded all 144
streams with aomdec; all 288 frames equaled the source. Artifacts and
the full SHA-256 manifest are retained in
`~/tmp/slower-preset-probe/sub8-inter-artifacts/` and
`~/tmp/slower-preset-probe/sub8-inter-manifest.tsv`. The compact verified
hash manifest is committed as `sub8_inter_2026-09-07.tsv` beside this note.

`dist::test::weighted_sse_includes_partial_chunks` checks every width and
height from 1 through 16, at 8/10/12-bit, using unequal strides and
nonuniform integer weights. The expected answer is an independent
per-pixel weighted square sum. Both scalar and dispatched paths are
checked; both no-default-features and assembly-enabled runs passed.

each of the three old implementations independently fails its regression:
the partition guard panics, the old plane clipping loses source chroma,

Following the project's intentional-coding-change procedure, exactly the
three fingerprints above were updated. A subsequent identity run passes
81 pinned cells with zero drift and all 360 toggle cells. No quality
threshold, capability setting or test assertion was weakened.
